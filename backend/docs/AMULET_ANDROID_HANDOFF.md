# 부적 저장·공유 프론트 연결 안내

상태: 복제본에 백엔드 구현·내부 테스트 완료. 실제 프론트 연결과 배포 API 호출 테스트는 하지 않았다.
요청·응답 예시는 [부적 API 명세](AMULET_API.md)를 따른다.

## 내 부적

1. 기존 운세·해석 응답과 직접 입력한 고민을 꾸미기 화면까지 유지한다.
2. 꾸민 앞면을 PNG 파일로 내보낸다. 최대 5MB(5242880바이트)다.
3. 저장 버튼에서 `POST /amulets`를 호출한다.
4. 응답의 `amulet_id`로 상세를 조회하고 보관함에 표시한다.

내 부적은 공유하지 않는다. 서버에서 이미지를 다시 꾸미거나 AI 해석을 새로 생성하지 않는다.

## 친구용 부적

1. 친구용 앞면 PNG와 당시 결과·입력한 상황을 `POST /amulets/shares`에 보낸다.
2. 반환된 `share_url`을 카카오톡 메시지에 넣는다.
3. 링크를 받은 앱은 로그인 상태를 확인한다.
4. 로그인한 경우에만 링크의 토큰을 `POST /amulets/shares/claim`에 보낸다.
5. 성공하면 반환된 `amulet_id`로 상세를 조회하고 앞면을 먼저 보여준다.

보낸 사람 보관함에는 저장하지 않는다. 먼저 수령한 한 계정만 받을 수 있고 유효기간은 없다.
같은 계정이 다시 받으면 기존 ID가 반환된다. 다른 계정이 받은 링크는 409다.

## 링크를 열었을 때

- 설치돼 있고 해당 도메인에 대한 Android App Links가 연결되면 앱이 링크를 처리한다.
- 앱이 없으면 서버의 `/share/{token}` 페이지에서 APK 설치 안내를 본다.
- 설치 후 앱에서 로그인하고 카카오톡의 원래 링크를 다시 누른다.
- 미로그인 상태에서는 수령 API를 호출하지 않는다. 로그인·회원가입 후 원래 링크 재방문을 안내한다.
- 공개 안내 페이지는 부적 데이터나 이미지를 반환하지 않으며 링크 방문만으로 수령하지 않는다.

## 보관함과 뒷면

| 화면 정보 | 백엔드 필드 |
| --- | --- |
| 만든 날짜 | `created_date` |
| 앞면 | 상세 응답의 `image_url` |
| 오늘의 운세 한마디 본문 | `fortune_summary` ← 기존 운세 `total_comment` |
| 그날의 기록 | `record` ← 입력한 고민 또는 친구 상황 |
| 맞춤 해석 | `day_message` |
| 행동 조언 | `action_advice` |
| 행운의 색 | `lucky_color` |

- `GET /amulets?month=YYYY-MM`으로 달력에 부적이 있는 날짜를 표시한다.
- `GET /amulets?date=YYYY-MM-DD`으로 해당 날짜 목록을 조회한다.
- 같은 날짜에 여러 부적이 있으면 목록에서 선택한다.
- 빈 목록이면 저장한 부적 없음 팝업을 표시한다.
- 상세에서 앞면을 먼저 보여주고 클릭 시 뒷면으로 뒤집는다.
- 이미지 URL은 5분 후 만료된다. 다시 열 때 상세 API에서 새 주소를 받는다.

## 아직 받아야 하는 설정

| 항목 | 현재 상태 / 필요한 작업 |
| --- | --- |
| 공유 기본 HTTPS 주소 | 미정. `AMULET_SHARE_BASE_URL`에 설정해야 공유 생성 가능 |
| APK 다운로드 HTTPS 주소 | 미정. `AMULET_APK_DOWNLOAD_URL` 설정 전에는 준비 중 안내 표시 |
| Android 패키지명 | 프론트 담당자에게 확인 필요 |
| 배포 APK 서명 인증서 SHA-256 | 프론트 담당자에게 확인 필요 |
| App Links | Android Manifest 설정과 공유 도메인의 `/.well-known/assetlinks.json` 연결 필요 |
| PNG 출력 해상도 | 프론트 출력에 맞춰 협의 |

실제 주소·패키지명·인증서 값은 임의로 작성하지 않았다.
카카오톡 SDK 연결·Android 구현·실기기 확인은 이 백엔드 작업에서 수행하지 않았다.

## 오류 표시

- 401: 로그인 안내
- 404: 부적 또는 공유 링크를 찾을 수 없음
- 409: 다른 계정이 이미 받은 부적
- 413: 파일 용량 초과
- 415: 정상 PNG가 아님
- 422: 입력 내용·조회 날짜 확인
- 503: 저장소 또는 공유 설정을 사용할 수 없음

저장 도중 통신이 끊겨 완료 여부를 모르는 경우 보관함을 먼저 확인한다.
내 부적 저장을 새로 요청하면 별도 부적이 생성될 수 있다.
