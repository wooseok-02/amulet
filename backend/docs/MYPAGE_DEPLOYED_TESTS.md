# 마이페이지 배포 서버 테스트 — 2026-11-17

대상: `https://amulet-api.onrender.com`  
배포 브랜치: `back`

처음에는 기능 브랜치만 푸시해 새 경로가 404였다. 이후 검증된 커밋을
실제 Render 배포 브랜치인 `back`에 fast-forward로 푸시했다. 1분 이상 지난 뒤
다시 호출한 결과를 아래에 기록한다.

| 순서 | 확인 항목 | 상태 | 실제 결과 |
| --- | --- | --- | --- |
| 1 | `GET /health` | 통과 | 200, `status: ok`, `environment: development` |
| 2 | `GET /health/supabase` | 통과 | 200, `status: ok` |
| 3 | OpenAPI에 새 경로 노출 | 통과 | `/api/v1/me`, `/api/v1/auth/logout` 모두 표시 |
| 4 | 토큰 없는 두 API 요청 | 통과 | 조회와 로그아웃 모두 401 |
| 5 | 합성 계정 A·B·C 회원가입 | 통과 | 세 요청 모두 201, access token 수신 |
| 6 | 본인 프로필과 사용자 정보 분리 | 통과 | A·B·C 조회 모두 200, 각자의 이름·이메일·필수 생년월일·성별·JSON 키 일치 |
| 7 | 양력·음력 평달·음력 윤달 | 통과 | A: `SOLAR/null`, B: `LUNAR/false`, C: `LUNAR/true` |
| 8 | 태어난 시간 | 통과 | A·C는 `null`, B는 `13:30` |
| 9 | 변조 토큰 조회 | 통과 | 401 |
| 10 | A 로그아웃과 사용자 분리 | 통과 | A 로그아웃 204·본문 없음, 같은 토큰 재조회 401, B 토큰 조회 200 |
| 11 | 만료된 실제 토큰 조회 | 미실행 | 만료된 유효 토큰을 확보하지 못함; 자동화 테스트에서 인증 오류 경로 검증 |
| 12 | 실제 서버의 로그아웃 상위 서비스 오류 | 미실행 | 운영 서버에 오류를 강제로 만들지 않음; 자동화 테스트에서 204 미반환 검증 |

합성 테스트 계정 3개는 Supabase Auth에 남아 있다. 실제 서버의
`environment` 값은 여전히 `development`다.
