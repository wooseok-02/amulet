# 부적 저장·공유 API 명세

이 문서는 2026-11-10 복제본에 구현한 백엔드 API 규격이다. 내부 테스트를 완료했으며,
실제 프론트·외부 API 호출 테스트는 사용자 요청에 따라 하지 않았다. 배포 상태는 [진행표](AMULET_STORAGE_AND_SHARING_PROGRESS.md)를 따른다.
기존 생성 API의 응답을 바꾸지 않고 부적 저장 단계에서 당시 값을 보존한다.

## 공통

- 인증: 모든 API에 `Authorization: Bearer {access_token}`.
- 업로드: `multipart/form-data`. PNG 실제 파일과 아래 텍스트 필드를 전달한다.
- PNG는 최대 5MB. 구현 용량 기준은 5 × 1024 × 1024바이트이며 빈 파일은 거부한다.
- `created_date`: Android에서 부적을 완성한 한국 날짜, `YYYY-MM-DD`. 유효한 날짜인지 검사한다.
- `record`: 기존 입력과 동일하게 빈 내용 불가, 최대 200자.
- 생성 결과를 다시 AI에 요청하지 않는다. 기존 문장의 앞뒤 공백 외 내용은 보존한다.
- 이미지 조회 URL에는 짧은 만료 시간을 둔다. 공유 링크 자체에는 유효기간이 없다.
- 목록·상세는 로그인한 사용자의 보관함만 조회한다.
- 실제 공유 주소·APK 주소·Android 이미지 해상도는 현재 미정이다. 임의 주소를 만들지 않는다.

## 업로드 필드

내 부적 저장과 친구용 공유 생성에서 같은 필드를 사용한다.

| 필드 | 형식 | 넣을 값 |
| --- | --- | --- |
| `image` | PNG 파일 | 꾸미기 완료한 앞면 |
| `fortune_summary` | 문자열 | 운세 응답의 `total_comment` |
| `record` | 문자열 | 내 고민 `concern` 또는 친구 상황 `situation` |
| `day_message` | 문자열 | 기존 해석 응답의 `day_message` |
| `action_advice` | 문자열 | 기존 해석 응답의 `action_advice` |
| `lucky_color` | 문자열 | 운세 응답의 `lucky_color` |
| `created_date` | 날짜 문자열 | 부적을 완성한 한국 날짜 |

파일을 제외한 필드 예시다. 실제 업로드는 JSON 요청이 아니라 위 multipart 형식이다.

```json
{
  "fortune_summary": "준비한 것을 믿고 한 걸음 내디디면 뜻밖의 도움을 만날 수 있는 날이에요.",
  "record": "면접을 앞두고 준비한 말을 잘 전할 수 있을지 걱정했어요.",
  "day_message": "완벽함보다 차분한 진심이 더 오래 기억되는 흐름이에요.",
  "action_advice": "첫 문장을 소리 내어 한 번 연습해보세요.",
  "lucky_color": "초록",
  "created_date": "2026-11-10"
}
```

## 1. 내 부적 저장

`POST /amulets`

업로드 필드를 받는다. 이미지·원본·본인 보관함을 저장한다. 내 부적의 공유 링크는 만들지 않는다.
성공 응답은 HTTP 201이다.

```json
{
  "amulet_id": "a2cad149-8303-4090-b858-944bc81c0435"
}
```

## 2. 친구용 공유 생성

`POST /amulets/shares`

업로드 필드를 받는다. 이미지·원본·공유 링크를 저장한다.
보낸 사람의 보관함에는 추가하지 않는다. 성공 응답은 HTTP 201이다.

```json
{
  "amulet_id": "a2cad149-8303-4090-b858-944bc81c0435",
  "share_url": "https://<설정한-공유-도메인>/share/<발급한-토큰>"
}
```

위 URL은 구조 설명용이다. 도메인이 설정되지 않으면 가짜 URL을 반환하지 않고
HTTP 503으로 설정 필요를 알린다. 설정 확인은 업로드 전에 수행한다.

## 3. 친구용 부적 수령

`POST /amulets/shares/claim`

```json
{
  "token": "<공유 링크에서 받은 원본 토큰>"
}
```

성공 응답은 HTTP 200이다.

```json
{
  "amulet_id": "a2cad149-8303-4090-b858-944bc81c0435"
}
```

- 첫 수령 계정을 기록하고 해당 계정 보관함에 추가한다.
- 같은 수령 계정의 재요청은 같은 ID를 반환한다.
- 다른 계정이 이미 받은 링크는 HTTP 409로 거부한다.
- 계정 기록과 보관함 저장을 한 DB 트랜잭션에서 처리한다.
- 수령 API는 로그인한 앱에서만 호출한다. 공개 링크 방문만으로 수령하지 않는다.

## 4. 보관함 목록

`GET /amulets?month=2026-11`

해당 한국 월에 만들어진 본인 보관함의 부적을 조회한다.
날짜별 조회는 `GET /amulets?date=2026-11-10`을 사용한다.
month와 date 중 하나만 전달하며 잘못된 필터는 HTTP 422다.
목록에서 선택한 ID로 상세 API를 호출한다. 성공 응답은 HTTP 200이다.

```json
{
  "items": [
    {
      "amulet_id": "a2cad149-8303-4090-b858-944bc81c0435",
      "created_date": "2026-11-10",
      "fortune_summary": "준비한 것을 믿고 한 걸음 내디디면 뜻밖의 도움을 만날 수 있는 날이에요.",
      "record": "면접을 앞두고 준비한 말을 잘 전할 수 있을지 걱정했어요.",
      "day_message": "완벽함보다 차분한 진심이 더 오래 기억되는 흐름이에요.",
      "action_advice": "첫 문장을 소리 내어 한 번 연습해보세요.",
      "lucky_color": "초록"
    }
  ]
}
```

없는 날짜·월은 HTTP 200과 `{"items": []}`를 반환한다.
앞면 이미지는 상세 API에서 조회한다.

## 5. 부적 상세

`GET /amulets/{amulet_id}`

본인 보관함에 있는지 확인한 후 앞면 이미지 임시 URL과 당시 결과를 반환한다.
성공 응답은 HTTP 200이다.

```json
{
  "amulet_id": "a2cad149-8303-4090-b858-944bc81c0435",
  "created_date": "2026-11-10",
  "fortune_summary": "준비한 것을 믿고 한 걸음 내디디면 뜻밖의 도움을 만날 수 있는 날이에요.",
  "record": "면접을 앞두고 준비한 말을 잘 전할 수 있을지 걱정했어요.",
  "day_message": "완벽함보다 차분한 진심이 더 오래 기억되는 흐름이에요.",
  "action_advice": "첫 문장을 소리 내어 한 번 연습해보세요.",
  "lucky_color": "초록",
  "image_url": "<Supabase가 발급한 만료 시간이 있는 이미지 URL>"
}
```

## 오류

기존 API와 동일하게 `{"detail": "설명"}` 형태를 사용한다.

| HTTP | 상황 |
| --- | --- |
| 401 | 로그인 정보 없음·만료 |
| 404 | 존재하지 않는 부적·토큰, 또는 본인 보관함에 없는 부적 |
| 409 | 다른 계정이 이미 수령 |
| 413 | 이미지 최대 용량 초과 |
| 415 | PNG가 아닌 이미지 또는 PNG 검증 실패 |
| 422 | 필수 값·날짜·입력 규격 오류 |
| 503 | DB·Storage·필수 설정을 사용할 수 없음 |

## 환경 설정과 실제 연결 대기

- 기존 Supabase URL·로그인 설정은 재사용한다.
- 부적용 비공개 버킷·계정별 접근 권한과 저장·수령 DB 함수는 실제 Supabase에 적용했다. 추가 관리자 키는 사용하지 않는다.
- 공유 기본 URL과 APK 다운로드 URL은 환경 변수로 나중에 설정한다.
- 카카오톡 SDK, Android App Links, 앱 식별자·서명 정보는 프론트 담당자와 연결한다.


프론트 전달 사항과 미정 설정은 [Android 연결 안내](AMULET_ANDROID_HANDOFF.md)를 참고한다.

## 설치·APK 배포 API

서버 HTML 설치 안내 페이지를 제거했다. 설치 JSON·APK 다운로드·Android 도메인 연결 API는 [1111_api.md](../../docs/1111_api.md)를 따른다. APK 등록 전 다운로드는 503이며 설치 정보는 apk_available=false다.
