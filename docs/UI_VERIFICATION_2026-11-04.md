## 검증 환경과 한계

Bukku_Test / Android API 36.1 에뮬레이터, SwiftShader, 화면 720×1600 / density 280.
초기 실행에서 Android 시스템 및 Pixel Launcher의 ANR 창이 화면을 가렸다.
이때의 실패와 가려진 캡처는 최종 통과로 계산하지 않았다. 오류창 정리와 빌드 프로세스 종료 후 재실행하여 위 결과를 얻었다.

이번 화면 검증은 명시적인 디자인 미리보기의 예시 데이터로 실행했다.
실제 서버 로그인·운세·AI 연동을 새로 통합 테스트했다는 의미는 아니다.
친구 이름/관계는 API 요청에 포함하지 않으며, 친구 생년월일/시간/성별은 보관함과 공유 이미지에 추가하지 않는다.

월간 해석·행운일과 알림은 API가 없어 예시/안내 상태다. 보관함은 계정·서버별 암호화된 기기 저장이며 서버 동기화 기능은 없다.
공유는 PNG와 Android 공유 시트를 구현했으며 수신 앱을 통한 실제 발송은 사용자가 완료한다.
실제 Android 휴대폰 검증은 별도로 남아 있다.
