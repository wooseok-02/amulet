## 화면 기능 상세

- 👤 SCR 2-1 · 친구의 기본 정보 입력
    
    **설명**
    
    - 친구의 운세를 확인하기 위해 필요한 기본 정보를 사용자가 직접 입력한다.
    
    **입력**
    
    !9B2ADE3D-D0D4-4872-826E-B45BB8604ECB.png
    
    **사용 방식**
    
    - 사용자가 친구의 정보를 수동으로 입력한다.
    
    **현재 미정 사항**
    
    - 모두 필수값으로 받는다.
- 🔮 SCR 2-2 · 친구 운세 확인
    
    **설명**
    
    - SCR 2-1에서 입력한 친구의 기본 정보를 바탕으로 친구의 오늘 운세를 보여준다.
    
    **입력**
    
    - SCR 2-1에서 입력한 친구의 기본 정보에서 **친구 이름은 제외**
    
    **사용자에게 제공하는 정보**
    
    - 미정
    
    **현재 미정 사항**
    
- 💭 SCR 2-3 · 친구의 구체적인 상황 입력
    
    **설명**
    
    - 친구가 현재 겪고 있는 상황이나 고민을 사용자가 대신 입력한다.
    
    **입력 후보**
    
    - SCR 1-2에서 받는 고민과 [같은 유형]과 상황 입력
    - 친구의 고민이나 현재 상황
    
    **출력** 
    
    - SCR 1-3과 동일
    
    **현재 미정 사항**
    
- ✨ SCR 2-4 · AI 맞춤 해석
    
    **설명**
    
    - 친구의 운세 정보와 구체적인 상황을 바탕으로, 친구에게 전달할 수 있는 맞춤형 해석과 조언을 AI가 제공한다.
    
    **입력**
    
    - SCR 2-2의 친구 운세 정보
    - SCR 2-3에서 입력한 친구의 상황·고민 정보
    
    **출력**
    
    - 미정
    
    **현재 미정 사항**
    
    - AI가 어떤 내용을 제공할지
    - 친구에게 직접 보여주는 문장인지, 부적을 만드는 사용자를 위한 설명인지
    - 결과를 어떤 형식과 순서로 보여줄지
- 🧿 SCR 2-5 · 부적 꾸미기
    
    **설명**
    
    - 친구에게 선물할 디지털 부적을 사용자가 직접 꾸미고 완성할 수 있다.
    
    **사용자가 할 수 있는 것**
    
    - SCR 1-4 와 동일
    
    **현재 미정 사항**
    
- 🧿 SCR 2-6 · 부적 저장 및 공유
    
    **설명**
    
    - 친구에게 선물할 디지털 부적을 사용자가 직접 꾸미고 완성할 수 있다.
    
    **사용자가 할 수 있는 것**
    
    - SCR 1-4 와 동일
    
    **현재 미정 사항**
