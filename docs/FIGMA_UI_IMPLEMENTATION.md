# Figma 화면 연결 구현

> 2026-11-11: 저장·공유는 `1111_api.md` 정책을 우선한다. 내 부적 공유는 제외하고 친구용 URL만 전달한다. 실제 보관함은 서버 API이며 미리보기만 기기 저장을 사용한다. 아래는 최초 디자인 확인 기록이다.

2026-11-04 사용자가 공유한 Figma Make를 로그인된 브라우저에서 직접 클릭하여 확인했다.

## 확인한 화면과 상태

- 홈: 나의 부적 / 친구에게 선물 전환, 오늘 운세, 고민·상황·감정 선택, AI 해석 열기/닫기.
- 친구 선물: 이름/별명, 생년월일, 시간 모름, 관계, 선택적 성별 → 친구 운세 → 친구 상황 → AI 응원 해석.
- 부적 1단계: 해/별/물결 문양, 한 줄/두 줄/점선 테두리, 미리보기, 해석으로 돌아가기.
- 부적 2단계: 개인/친구별 완성 문구, 보관함 저장 또는 친구에게 선물, 이미지 공유, 편집으로 돌아가기.
- 보관함: 이전/다음 달, 날짜 선택, 저장 표시, 행운일, 월간 운세 카드, 날짜별 팝업, 부적 앞/뒷면 전환.
- 내 정보: 로그인, 회원가입, 로그인 후 이름·이메일·생일·달력·시간·성별, 로그아웃.
- 공통: 로고, 알림 버튼, 홈/보관함/내 정보 내비게이션.

## 구현 경계

인증 및 개인/친구 운세·해석은 기존 FastAPI를 사용한다. 디자인 미리보기는 명시적인 예시 데이터다.
월간 운세 API가 없어 월간 카드와 행운일은 예시로 표시한다. 보관함은 기기 내 저장이며 서버 저장으로 표시하지 않는다.
친구 선물과 공유는 Android 공유 시트를 열며 실제 전송은 사용자가 수신 앱에서 완료한다.
Figma에 없는 회원가입 윤달 및 친구 양력/음력 선택은 docs 요구사항에 맞춰 보완한다.
타이포그래피와 여백은 기존 Compose 디자인 토큰을 사용하며 작은 휴대폰 화면에 맞게 재배치한다.
