## 화면 기능 상세

- 📝 SCR 3-1 · 회원가입
    
    **설명**
    
    - 사용자가 서비스 이용에 필요한 계정을 생성한다.
    - 이메일 인증은 진행하지 않고, 이메일 형식만 확인한다.
    - 회원가입이 완료되면 별도 로그인 없이 바로 메인 화면(SCR-1)으로 이동한다.
    
    **입력 정보**
    
    - 이메일
    - 비밀번호
    - 비밀번호 확인
    - 사용자 이름
    - 생년월일
    - 양력 / 음력 선택
    - 윤달 여부 (음력 선택 시)
    - 태어난 시간
    - 성별
    
    **입력 조건**
    
    - 이메일: 이메일 형식에 맞아야 한다.
    - 비밀번호: 영문과 숫자를 모두 포함하고 최소 8자 이상이어야 한다.
    - 특수문자: 선택 사항이다.
    - 비밀번호 확인: 비밀번호와 동일해야 한다.
    - 사용자 이름: 2자 이상 4자 이하이며, 다른 사용자와 중복될 수 있다.
    - 생년월일: 1900년부터 현재 연도까지 입력할 수 있다.
    - 생년월일은 양력 또는 음력을 선택해 입력한다.
    - 음력을 선택한 경우 윤달 여부를 함께 선택할 수 있다.
    - 태어난 시간: 선택 입력이며 공란을 허용한다.
    - 태어난 시간 입력 시 시간 선택 UI를 사용한다.
    - 성별: 남성 / 여성 중 하나를 선택한다.
    
    **오류 처리**
    
    - 이메일 형식이 올바르지 않으면 이메일 형식 오류를 표시한다.
    - 이미 가입된 이메일이면 중복 이메일 오류를 표시한다.
    - 비밀번호가 영문 + 숫자 포함, 최소 8자 조건을 만족하지 않으면 비밀번호 형식 오류를 표시한다.
    - 비밀번호와 비밀번호 확인 값이 다르면 비밀번호 불일치 오류를 표시한다.
    - 사용자 이름이 2자 이상 4자 이하 조건을 만족하지 않으면 이름 길이 오류를 표시한다.
    - 생년월일이 1900년부터 현재 연도까지의 범위를 벗어나면 생년월일 범위 오류를 표시한다.
    
    **회원가입 완료 후**
    
    - 계정을 생성한다.
    - 바로 로그인 상태로 처리한다.
    - 메인 화면(SCR-1)으로 이동한다.
    
    **이번 범위에서 제외**
    
    - 이메일 인증
    - 비밀번호 재설정
    - 회원 탈퇴
    - 소셜 로그인
- 🔑 SCR 3-2 · 로그인
    
    **설명**
    
    - 기존 사용자가 이메일과 비밀번호를 입력해 로그인한다.
    
    **입력 정보**
    
    - 이메일
    - 비밀번호
    
    **로그인 성공 시**
    
    - 로그인 상태를 저장한다.
    - 메인 화면(SCR-1)으로 이동한다.
    
    **로그인 실패 시**
    
    - 이메일 존재 여부와 비밀번호 오류를 구분하지 않는다.
    - 다음 메시지로 통일한다.
    - **“이메일 또는 비밀번호가 올바르지 않습니다.”**
    
    **이번 범위에서 제외**
    
    - 비밀번호 찾기
    - 소셜 로그인
- 🔄 SCR 3-3 · 자동 로그인
    
    **설명**
    
    - 사용자가 한 번 정상적으로 로그인한 이후에는 앱을 다시 실행해도 로그인 상태를 유지한다.
    
    **동작**
    
    - 저장된 로그인 상태가 유효하면 로그인 화면을 생략한다.
    - 바로 메인 화면(SCR-1)으로 이동한다.
    
    **로그인 화면으로 이동하는 경우**
    
    - 처음 앱을 실행한 사용자
    - 로그인 정보가 없는 사용자
    - 로그아웃한 사용자

## 확정된 회원가입 규칙

| 항목 | 규칙 |
| --- | --- |
| 이메일 | 이메일 형식만 검사 / 별도 이메일 인증 없음 |
| 비밀번호 | 영문 + 숫자 포함 / 최소 8자 / 특수문자 선택 |
| 비밀번호 확인 | 비밀번호와 동일해야 함 |
| 사용자 이름 | 2자 이상 4자 이하 / 중복 허용 |
| 생년월일 | 1900년부터 현재 연도까지 / 양력·음력 모두 지원 |
| 윤달 | 음력 선택 시 윤달 여부 선택 및 저장 |
| 태어난 시간 | 선택 입력 / 공란 허용 / 시간 선택 방식 |
| 성별 | 남성 / 여성 |
