## SCR 1-1 · 나의 오늘 운세 확인

회원가입 때 저장한 사용자의 생년월일, 양력·음력, 윤달 여부, 태어난 시간,
성별과 오늘 날짜를 OpenAI에 전달해 오늘 운세를 생성한다.

### 제공 정보

- 날짜
- 운세 제목 한 줄
- 총합 운 코멘트 한 줄
- 총운 점수: 0~100
- 애정운 점수: 0~100
- 금전운 점수: 0~100
- 직장운 점수: 0~100
- 학업운 점수: 0~100
- 건강운 점수: 0~100
- 행운 숫자 1개: 0~10
- 행운 색: 색 이름만 제공
- 오늘의 행동 한 줄

### 생성·보관 규칙

- 날짜 기준은 `Asia/Seoul`이다.
- 사용자별로 하루에 운세 하나만 생성한다.
- 생성 결과는 `daily_fortunes`에 저장한다.
- 같은 날 다시 조회하면 저장된 결과를 반환하고 OpenAI를 다시 호출하지 않는다.
- 동시에 여러 요청이 들어와도 먼저 저장된 운세를 해당 날짜의 결과로 사용한다.

## SCR 1-2 · 나의 고민 입력

### 상황 선택

- 전체
- 연애
- 금전
- 취업
- 학업
- 건강
- 인간관계

### 나의 고민

- 직접 입력
- 최대 200자
- 빈 내용은 허용하지 않음

### 현재 마음

다음 중 하나만 선택한다.

- 불안해요
- 우울해요
- 답답해요
- 용기가 필요해요

고민 입력값은 DB에 저장하지 않는다. 사용자가 앱을 종료하면 유지하지 않는 임시
화면 상태로 사용한다.

## SCR 1-3 · AI 맞춤 해석

오늘 운세, 사용자 사주 정보, 상황, 고민 내용, 현재 마음을 OpenAI에 전달한다.

### 출력

- 오늘이 어떤 날인지 설명하는 문장 한 줄
- 지금 할 수 있는 구체적인 행동 조언 한 줄

해석 API는 결과를 DB에 저장하지 않고 응답으로만 전달한다. 다만 부적을
저장·공유할 때는 당시 운세 한마디·맞춤 해석·행운의 색을 별도로 보존한다.
직접 입력한 고민·친구 상황 원문은 보존하지 않는다.
상세 규칙은 [보관함](SCR_4.md)과 [저장·공유 초안](AMULET_STORAGE_AND_SHARING.md)을 따른다.

---

## SCR 1-4 · 부적 만들기

사용자가 AI 맞춤 해석을 확인한 뒤 Android 앱에서 직접 부적을 꾸민다.

- 시스템 제공 디자인 템플릿
- 기본 프레임
- 자유 배치 텍스트 박스
- 픽셀 크기 설정

부적을 만드는 과정에는 백엔드가 개입하지 않는다.

## SCR 1 백엔드 API

모든 요청에 로그인 후 받은 Access Token을 보낸다.

```http
Authorization: Bearer {access_token}
```

| 기능 | Method | Endpoint |
| --- | --- | --- |
| 오늘 운세 조회·생성 | `GET` | `/fortune/today` |
| 고민 맞춤 해석 | `POST` | `/fortune/interpret` |

백엔드 내부 테스트와 운영 DB 스키마 적용을 완료했다. 2026-10-14 가상 입력으로
실제 OpenAI 생성 코드 호출(내 운세·고민 해석)을 확인했다. 인증·DB·Android를
포함한 통합 테스트는 남아 있다. 상세 결과와 연결 체크리스트는
[작업 진행사항](../WORK_PROGRESS.md)을 참고한다.
