## 화면 기능 상세

- 🔮 SCR 1-1 · 나의 오늘 운세 확인
    
    **설명**
    
    - 사용자의 사주/운세 정보를 기준으로 오늘의 운세를 보여준다.
    
    **사용자에게 제공하는 정보**
    
    - 총 운세 점수
    - 총합 운 코멘트
    - 한 줄 코멘트
    - 모든 운 퍼센트
        
        !총 운세.png
        
    - 행운 숫자 (점수에 따라서 색이 바뀌면 좋다~)
    - 행운 색
    - 오늘의 행동
    
    **현재 미정 사항**
    
    - 오늘 운세에서 어떤 정보를 보여줄지
        - (사용자에게 제공하는 정보)
    - 운세 계산을 위해 사용자에게 어떤 정보를 받을지
        - 사용자 기본 정보
    - 해당 정보를 어떤 방식으로 입력받을지
        - 회원가입할때 입력된 사용자의 기존 정보
- 💭 SCR 1-2 · 나의 고민 입력
    
    **설명**
    
    - 사용자가 현재 고민이나 상황을 입력할 수 있다.
    
    **입력 후보**
    
    !고민 리스트.png
    
    - 상황 선택 : 컨텍스트 형태로 아래로 스크롤내리도록 수정
    - 나의 고민
    - 현재 마음 상태
    
    **현재 미정 사항**
    
    - 상황 카테고리를 어떤 방식으로 제공할지
    - 고민 입력 형식과 범위
    - 마음 상태를 어떤 방식으로 입력받을지
- ✨ SCR 1-3 · AI 맞춤 해석
    
    **설명**
    
    - 사용자의 고민 입력값과 사주/운세 정보를 바탕으로 AI가 맞춤형 해석과 조언을 제공한다.
    
    **입력**
    
    - SCR 1-1의 사용자 사주/운세 정보
    - SCR 1-2에서 입력한 고민·상황·마음 상태
    
    **출력**
    
    - 입력 정보를 바탕으로 한줄~두줄 정도로 보여주기.
    
    **현재 미정 사항**
    
    - AI가 어떤 내용을 제공할지
    - 결과를 어떤 형식과 순서로 보여줄지
- 🧿 SCR 1-4 · 부적 만들기
    
    **설명**
    
    - 사용자가 자신의 디지털 부적을 직접 꾸미고 완성할 수 있다.
    
    **사용자가 할 수 있는 것**
    
    - 부적 픽셀 크기 설정
    - 시스템이 제공하는 기본 디자인 템플릿
    - 기본 프레임
    - 텍스트 박스 ( 자유 배치 )
    
    **현재 미정 사항**
    
    - 어떤 요소를 꾸밀 수 있게 할지
    - 부적 생성과 꾸미기 방식을 어떻게 구성할지
    - 완성된 부적의 저장·활용 범위
- 🧿 SCR 1-5 · 부적 저장 및 공유
    
    **설명**
    
    - 사용자가 자신의 디지털 부적을 확인하고 보관함 저장 혹은 부적 공유를 할 수 있다.
    
    **화면에 보이는 것**
    
    - 만들어진 부적
        - 앞면 : 부적 이미지
        - 뒷면 : 부적의 의미 설명
    - 부적 보관함 저장
    - 부적 공유하기
        - 카카오톡 메시지 링크로 공유
    
    **현재 미정 사항**
    
    - 어떤 요소를 꾸밀 수 있게 할지
    - 부적 생성과 꾸미기 방식을 어떻게 구성할지
    - 완성된 부적의 저장·활용 범위
