# 보관함 - SCR 4

확인일: 2026-11-04. 사용자가 전달한 Notion의 두 보관함 문서에서 동일한 핵심 요구사항을 확인했다.
원문: https://app.notion.com/p/SCR_4-3f9590c0a92680059195f8d579156eb7

## SCR 4-1 월별 부적 캘린더

- 현재 연도/월, 월별 캘린더, 이전 달/다음 달 이동.
- 부적이 있는 날짜는 배경과 표시점으로 구분.
- 행운일은 날짜 왼쪽 상단 네잎클로버 표시.

## SCR 4-2 날짜 선택

- 저장한 날짜를 선택하면 그날의 부적을 팝업으로 표시.
- 빈 날짜를 선택하면 저장한 부적이 없다는 안내 팝업 표시.
- 같은 날짜에 여러 부적을 저장한 경우 팝업에서 선택 가능.

## SCR 4-3 부적 상세 / 뒷면

- 부적을 누르면 3D 회전으로 앞면/뒷면 전환.
- 날짜, 당시 기록, 운세 한마디, 상황과 운세에 대한 해석, 행운의 색 표시.
- 일반 고민 입력은 임시 상태다. 사용자가 부적 저장을 누른 경우에만 기록 스냅샷을 암호화된 기기 보관함에 저장한다.
- 친구의 생년월일, 시간, 성별 및 관계는 저장·공유 이미지에 포함하지 않는다.

## SCR 4-4 월간 요약

- 월 평균 점수, 총운 키워드, AI 종합 해석 표시.
- 원문에서 월간 생성 방법과 데이터 기준은 추후 정의 대상으로 명시.
- 현재 월간 API가 없어 종합 해석과 행운일은 예시라고 표시한다.
- 저장된 날짜별 점수가 있으면 그 날짜들의 평균을 계산하고 집계 일수를 명시한다. 전체 월 데이터 평균이라고 표시하지 않는다.

## 저장 및 공유

- 보관함 서버 API가 없으므로 사용자/서버별로 분리된 기기 저장소를 사용한다.
- Android Keystore 키로 저장 내용을 암호화한다.
- 이미지 공유는 Android 공유 시트까지만 열고 실제 발송은 사용자가 수행한다.
